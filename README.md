# Binary Search Tree

A menu-driven Java application that supports:

- Inserting values (duplicates are rejected)
- Deleting values
- Displaying values in ascending order using inorder traversal
- Displaying the smallest and largest values
- Searching for a value
- Counting the nodes

## Run

A Java JDK must be installed. Open a terminal in the folder containing both Java files.

Compile:
```bash
javac BST.java BST_Menu.java
```

Run:
```bash
java BST_Menu
```
